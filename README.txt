あみてる出荷画像 Webアプリ版

公開するファイル:
- index.html
- app.js
- manifest.webmanifest
- sw.js

GitHub PagesなどHTTPSのWebサーバーに、この4ファイルを同じ場所へ置いてください。
公開URLをiPhoneのSafariで開けば動作します。

初回:
1. 品種名＋代表写真を登録
2. 商品ごとに3〜4品種を選択
3. 「ミックス画像を作る」
4. 完成画像を長押しして写真に保存

現物写真:
「現物写真を選ぶ」→ 自動縮小 → 長押し保存

ホーム画面:
Safariの共有 → ホーム画面に追加

写真はJavaScriptでiPhone内処理し、アプリ自身は画像をサーバーへアップロードしません。
